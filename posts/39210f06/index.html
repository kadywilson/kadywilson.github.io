本地智能桌宠第二期更新记录

第二期桌宠主要完成了 v2、v3 和 v4 功能迭代，重点是增强 AI 对话体验、语音朗读以及天气功能。

v2 Chat Panel & Memory

完成内容

  • Chat Panel 短对话输入框
    • 位于桌宠下方，半透明，随桌宠移动。
    • 输入内容后调用 AI 回复。
    • 使用 config/persona.yaml + config/chat.yaml 提供 prompt 和个性化语气。
  • 托盘菜单更新
    • 增加 Show Chat / Hide Chat。
    • 支持右键桌宠打开功能菜单，同步托盘逻辑。
  • Chat 记忆
    • JSONL 格式短对话记忆：data/chat_memory/active_chat.jsonl。
    • 支持归档 active_chat.jsonl 到 archive 目录，开启新的活跃记忆段落。
    • Poke 与 Todo 提醒不写入 Chat memory，保证对话独立。

UI 修复与优化

  • 自定义系统托盘图标和应用窗口图标
    • 图标加载顺序：assets/icons/tray.ico > assets/icons/tray.png > fallback 蓝圈。
  • 右键桌宠打开功能菜单
    • 复用系统托盘菜单逻辑，操作一致。
  • 气泡与表情
    • 气泡点击关闭，表情恢复默认。
    • 支持四种表情：default / happy / annoyed / upset。
    • 支持 manifest.json 控制表情路径和桌宠尺寸。

v3 TTS 语音朗读

功能概述

  • 气泡显示最终 AI 回复时自动朗读：
    • 包含 Poke / Chat / Reminder 场景。
    • Thinking bubble（“我想想……”）不朗读。
  • Voice On / Off 菜单切换
    • 立即生效，静音模式不调用 TTS API。
  • 播放与缓存
    • 新气泡到来时中断旧音频播放。
    • TTS 合成在后台线程，UI 不阻塞。
    • 缓存已合成音频（md5 hash），重复文本直接播放。
    • 缓存自动清理：按天（默认 2 天）+ 按数量（默认 300 个）。

TTS 接入详细说明

  1. Provider：Volcengine / 豆包语音
  2. Endpoint：

https://openspeech.bytedance.com/api/v3/tts/unidirectional

  1. 鉴权：
  • X-Api-Key
  • X-Api-Resource-Id（新版控制台）
  • Resource ID 示例：seed-tts-2.0
  1. Voice：zh_male_kailangdidi_uranus_bigtts（开朗弟弟 2.0）
  2. 情感控制：
  • additions.context_texts 可传入上下文文本。
  • audio_params.emotion 预留接口支持未来扩展。

v4 Weather / 今日天气

功能概述

  • 托盘菜单与右键菜单增加：
  • Weather Today / Weather Tomorrow
  • 点击后异步请求 wttr.in 获取天气数据。
  • 气泡显示中文天气摘要，含简单建议。
  • 支持 Voice 自动朗读（可配置 weather.behavior.speak_if_voice_enabled）。

技术细节

  • 数据源：

https://wttr.in/{location}?format=j1

  • {location} 来自 config/weather.yaml 手动配置。

  • 仅支持手动输入城市名或机场代码，避免使用 GPS / IP 定位。

  • 缓存

  • 文件路径：data/weather_cache/current_weather.json

  • TTL：30 分钟

  • 启动时自动清理过期缓存

  • 成功请求后写入缓存，缓存命中直接使用，不请求 API。

  • 容错

  • 网络失败或解析错误使用本地 fallback 文案：

  • 不影响 Chat / TTS / Todo / Reminder。

  • 异步请求

  • 使用后台线程，保证 UI 不阻塞。

  • 失败仅记录日志，不弹错误窗口。

总结

第二期主要完成：

  1. v2：Chat Panel、短对话、Chat 记忆与归档。
  2. v3：TTS 语音朗读、播放控制、缓存机制。
  3. v4：Weather 今日/明日天气查询、中文气泡显示、TTS 朗读支持、缓存机制。

整个迭代保持了：

  • UI 线程不阻塞。
  • Chat 与 Weather 数据互不污染。
  • 失败路径有 fallback，保证程序稳定。
  • 静默启动、日志功能完善，方便调试。

桌宠现在可以作为日常小工具使用，并提供更自然的 AI 互动体验和语音陪伴。
